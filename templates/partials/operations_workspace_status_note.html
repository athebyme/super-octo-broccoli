{% if operation.status == 'queued' %}

Операция ещё не отправлена в Ozon. Кнопка отправки запускает отдельную запись и последующую сверку.

{% elif operation.status == 'submitting' %}

Отправка в Ozon началась. Не создавайте повторное изменение; дождитесь сохранённого результата операции.

{% elif operation.status in ['submitted', 'polling'] %}

Ozon получил запрос, результат ещё проверяется. Можно проверить статус операции; повторная запись не запускается.

{% elif operation.status == 'uncertain' %}

Точный результат записи неизвестен. Повтор запрещён; доступна только сверка или разбор операции.

{% elif operation.status == 'partial' %}

Завершилась только часть изменений. Проверьте каждую строку и фактическое состояние в Ozon; не повторяйте весь набор.

{% elif operation.status == 'failed' %}

Операция завершилась с ошибкой. Сначала проверьте причину и состояние карточки в Ozon; новое действие создавайте только после повторного просмотра точных значений.

{% elif operation.status == 'succeeded' %}

Результат записи подтверждён. Это статус операции, а не подтверждение отображения карточки в продаже; снимок и результат доступны ниже.

{% elif operation.status == 'cancelled' %}

Операция отменена. Перед новым изменением проверьте, не успела ли запись попасть в Ozon.

{% else %}

Состояние операции не распознано. Не повторяйте запись; откройте технические сведения и сверяйте состояние только штатным способом.

{% endif %}
