Где взять Client-Id и API key?
  1. Откройте свой магазин в Ozon Seller и раздел API-ключей.
  2. Создайте ключ для Seller API и скопируйте Client-Id этого же магазина. Ключ рекламного Performance API сюда не подходит.
  3. Для загрузки каталога нужны права чтения товаров, цен и остатков. Для будущей отправки карточек отдельно понадобится право управления товарами.
  4. Вставьте значения ниже. Seller Hub проверит подключение и начнёт загрузку автоматически.
