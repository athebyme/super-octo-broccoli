# Рабочий экран заказов Ozon

25.09.2026. Следующий пакет общего плана, W6/W9. Публикация/отгрузка и read-only обзор — разные gates; этот пакет завершает обзор и навигацию, но не объявляет несуществующие shipping/reply writes готовыми.

## Направление

Рабочий список продавца: номер отправления, реальные фото и состав, наблюдённый статус, схема и дата. На desktop строки с общей сеткой, на mobile те же строки превращаются в компактные блоки без горизонтального скролла. Подробности отправления открываются в доступной панели: состав, связь с каталогом, даты и только наблюдённая история статусов. Контекст кабинета, периода, поиска, статуса, схемы, страницы и открытого отправления живёт в URL.

Используем существующую тему Seller Hub: `--bg` #faf9f7, `--bg-card` #ffffff, `--text` #1a1a1a, `--text-secondary` #6b6b6b, `--accent` #c45d3e, `--border` #e8e5e1; dark берётся из штатных токенов. Hex перечислены как описание текущей палитры, в CSS используются переменные. Заголовки — Instrument Serif из `--font-display`, данные и controls — штатный `--font-body`, цифры tabular. Основное выравнивание слева; карточки до 8px, тени только у overlay. Иконки из существующего реестра. Визуальный акцент — фотографии реальных товаров, декоративная генерация изображений не нужна.

```
Заказы Ozon                       период / обновление
канал и кабинет
Заказы | Возвраты | Отмены
наблюдённая свежесть / состояние фонового обновления
поиск                         схема / статус
[фото] номер, состав           статус   дата   открыть
[фото] номер, состав           статус   дата   открыть
страница и результат фильтра
```

Проверка против задачи: отказ от ещё одной KPI-панели — неизвестные бизнес-показатели не выдумываются. Статусные фильтры считают сохранённые отправления выбранного scope, а не размер видимой страницы. Пустой фильтр предлагает сбросить условия; новый кабинет предлагает загрузить данные. Ошибка сохраняет последние подтверждённые результаты с их scope. Прошлый успешный snapshot не выдаётся за завершение текущей загрузки. Валюта не подменяется RUB, денежный ноль не скрывается. Неизвестный статус остаётся видимым фактом.

## Контракт реализации и проверки

- Vue внутри `x-ignore`, единый Flask shell и channel bar сохраняются. Classic Alpine fulfillment заменяется с функциональным паритетом; остальные страницы не меняют стек этим пакетом.
- Существующие list/detail API остаются seller/account-scoped. Для рабочего списка — явное компактное представление с bounded batch reads; полный состав доступен постранично в detail. Images/links допускаются только по точному seller/account listing FK, никаких fuzzy SKU/title match и provider I/O в HTTP.
- Состояния refresh переиспользуют общий `ozonReadRefresh`: один POST enqueue, далее GET status, visible-tab gate, timeout, revision gate, отсутствие success до completed. После неизвестного исхода POST сначала проверяется состояние заявки. Программные ошибки не превращаются в пустой список.
- History Back/Forward, Esc, focus return, reload/deep link, смена периода во время запроса, истёкшая сессия, 429/waiting, late response, пустые данные/пустой фильтр, неизвестная валюта/ноль, чужой FK и большие отправления входят в проверки.
- Реальный read snapshot на старте: 45 отправлений, 7 возвратов, 8 отмен account 1. Это не синтетические proof для отгрузки. Полный FBS write-цикл и точный контракт этикеток остаются отдельной работой W9.
