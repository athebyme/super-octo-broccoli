# Отзывы и вопросы Ozon: рабочее место продавца

## План и границы

1. Перенести существующую ленту на Vue 3 в общей оболочке Seller Hub. Сохранить кабинеты, разделы, статусы, поиск, страницы и подготовку локального ответа.
2. Добавить точно связанные фотографии и переход в карточку. Проверять seller/marketplace/account также у связанных listing и draft; чужая или неоднозначная связь не даёт фактов для UI и ИИ. Поиск `%`/`_` буквальный.
3. Открывать входящее в отдельном доступном диалоге: полный текст, наблюдённый статус, черновик, ручное редактирование, сохранение и копирование. Локальное сохранение требует версии черновика и повторной проверки исходного входящего/фактов; прежняя версия сохраняется как superseded.
4. URL хранит раздел, фильтры, страницу и открытое входящее. GET ограничен временем, устаревшие ответы отбрасываются. Ошибка сохраняет прежнюю выборку и ввод. Неизвестный исход POST блокирует повтор до чтения сохранённого состояния; автоматических повторов POST нет.
5. Проверить tenant isolation, конкурентное редактирование, потерянные ответы, обе темы, клавиатуру, мобильные размеры и длинный контент. Затем собрать и проверить конкретный образ, развернуть и повторить production read-only проверки.

Этот этап не открывает отправку ответов в Ozon. Схема отправки/подтверждения/read-back остаётся отдельным W9 gate. Ручное обновление пока использует существующий bounded read endpoint, одна попытка до трёх страниц; фоновый scheduler продолжает незавершённый run. Перенос этого старого refresh в общую durable request queue остаётся отдельной задачей. Никаких новых provider endpoints, подписок или вызовов при открытии страницы.

## Визуальное решение

Сохраняем тему «Тёплая редакция»: светлый фон `#faf9f7`, поверхность `#ffffff`, текст `#1a1a1a`, акцент `#c45d3e`, граница `#e8e5e1`; в реализации только существующие CSS tokens и их dark-варианты. Inter для списков и форм, существующий Instrument Serif только в заголовке страницы. Реальные фото товаров и общие outline-иконки вместо декоративной новой иллюстрации.

Компоновка — спокойная лента обращений с крупным текстом покупателя, маленькой карточкой товара и явным действием «Подготовить ответ». Статусы представлены компактными фильтрами с наблюдёнными числами, без одинаковых больших KPI-карточек. Диалог сосредоточен на конкретном обращении и ответе; на телефоне занимает доступную ширину.

```text
Отзывы и вопросы                         Обновить из Ozon
Канал / выбранный магазин
Отзывы | Вопросы     Все / Новые / Просмотренные / Обработанные
Поиск                                     Актуальность
[фото] Товар, артикул                      Оценка и дата
Текст обращения                           Открыть ответ

Диалог: товар → обращение → локальный ответ → сохранить / копировать
```

Проверка плана: общая тема уже закреплена продуктом; новый декоративный hero или новая палитра нарушили бы цельность. Выразительность здесь дают фотографии и читаемая переписка. Нули без полного наблюдения не означают отсутствие обращений; отказ Ozon показывается как недоступность раздела, без установленной причины о тарифе.
