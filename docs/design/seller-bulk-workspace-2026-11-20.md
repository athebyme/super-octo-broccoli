# Массовая работа с товарами

Продавец начинает с «Моих товаров». Верхняя строка ведёт к импорту из каталога поставщика, ценам и карточкам на площадках. После выбора товаров интерфейс показывает размер набора и предлагает действия для него. Создание карточек и изменение цен требуют указать площадку и кабинет там, где операция относится к конкретному получателю.

## Входы в сценарии

| Действие | Экран и результат |
| --- | --- |
| Изменить карточки | Общий редактор `/my-products/common-content` принимает точный набор до 50 внутренних товаров. Для опубликованных карточек WB используется выбор в `/products` и существующий массовый редактор. |
| Изменить цены | Выбор карточек WB переносится в `/prices/change` после проверки полного набора. В ценах Ozon можно выбрать до 100 карточек одного кабинета или перенести точный выбор из «Моих товаров». Продавец задаёт цену или процент, видит расчёт и причины пропусков, сохраняет заявки и отдельно подтверждает отправку. |
| Создать карточки | Выбор в `/my-products/beta`. Для Ozon готовятся черновики с отдельной проверкой и отправкой в выбранный кабинет. Для WB используется действующий сценарий отправки новых карточек. |
| Импортировать товары | `/supplier-catalog` открывает выбор поставщика. Действие в его каталоге создаёт внутренние товары для подготовки. |
| Обновить от поставщика | Выбор товаров с обновлениями открывает применение к внутренним товарам. Итог показывает обновлённые карточки, пропуски и ошибки по выбранному набору. Действия с фотографиями опубликованных карточек WB доступны в контексте WB. |

## Заметка о скрываемых элементах

| Элемент | Место доступа |
| --- | --- |
| Параллельные пункты «Внутренние товары» и «Новая версия» | Один основной вход «Мои товары». Прежний список открывается из контекста рабочего экрана и по ссылке `/my-products`. |
| Постоянные кнопки сверки, обогащения и удаления | Дополнительные действия выделенного набора. Удаление требует отдельного подтверждения. |
| Технические журналы и диагностика в настройках | Раскрываемые дополнительные настройки рядом с подключениями. |
| Общая кнопка «Мои подключения» в списке уже подключённых кабинетов | «Кабинеты Ozon» в строке настроек и «Статус и настройки» у конкретного кабинета. |
| Плашки этапов подключения Ozon | Текущее состояние и следующее действие в карточке кабинета. |
| «Центр уведомлений» в основной строке настроек | Кнопка уведомлений в верхней панели и дополнительные настройки. |
| Обогащение при импорте как основная кнопка | «Обогатить перед импортом» в настройках импорта у конкретного поставщика. |
| Синхронизация цен всего кабинета внутри фиксированного выбора WB | Кнопка синхронизации доступна через обычный вход в цены WB. |

## Композиция и проверка

Одна линия действий над списком, выбранные товары и доступные действия рядом со счётчиком. На узком экране элементы переносятся на следующую строку. Названия совпадают на входе, в подтверждении и в результате. Для импорта, локального обновления, создания черновика и записи на площадку используются названия соответствующих действий.

Сохраняем действующую типографику Seller Hub. Instrument Serif служит заголовкам, Inter используется для данных и кнопок. Существующие токены задают светлый фон `#faf9f7`, основной текст `#1a1a1a`, акцент действия `#a34a2f`, тёмный фон `#131211` и тёмный текст `#ebe7e2`. Акцент показывает основное действие текущего шага. Интерфейс опирается на строки, выделение выбора и компактные пояснения результата.

Приёмка требует обычных переходов и сохранения получателя, точного набора до подтверждения, отказа при устаревшем выборе, результатов по выбранным товарам, работы с клавиатуры и читаемости в обеих темах на узком и широком экране.
