## 💡 Предложено — топ (высокая отдача, стоит на готовых данных)

1. **«Что делать сегодня» — операционный кокпит.** На дашборде приоритетный список действий
   из существующих сигналов: N карточек просели (`Product.attention_reasons`), M на исходе
   остатка, K ниже маржи, L ушли в тень/заблокированы (`blocked_cards`), P задач упало.
   Клик → к ним (с выбором → в панель массовых действий / ИИ-чат). Опора: quality-скорер,
   остатки, finances, blocked_cards.
2. **Проактивные алерты в систему уведомлений.** Scheduler-job шлёт: «остаток закончится
   через N дней при текущих продажах», «маржа ниже минимальной», «карточка ушла в тень/блок»,
   «просадка заказов по SKU», «новый негативный отзыв». Опора: система уведомлений (`Notification`,
   `create_notification`) + scheduler.
3. **Здоровье фоновых задач + авто-реапер.** Reaper помечает застрявшие `running/pending`
   джобы (EnrichmentJob и др.) как `failed` + уведомляет; страница «Система» со статусом
   воркеров/синков. Мотив: зомби-джобы — системная болячка (несколько типов джоб так виснут;
   трей уже фильтрует их отображение, но данные в БД не финализируются).
4. **Юнит-экономика по карточке (P&L).** Рентабельность каждого товара: выручка − комиссия WB
   − логистика − хранение − себестоимость (`supplier_price`) → прибыль/маржа в строке и на
   карточке. Опора: finances (комиссии/логистика уже тянутся), supplier_price.
5. **Сохранённые виды + действия из ⌘K.** Сохранять фильтры («просевшие», «без остатков»,
   «ниже маржи») в один клик; ⌘K не только навигирует, но и запускает действия («обнови
   остатки», «синк цен», «перейти к nmID»). Опора: products-фильтры, ⌘K-палитра.

## 💡 Предложено — по темам

**Инсайт / решения**
- ABC-анализ каталога (A/B/C по вкладу в выручку).
- Спарклайны в строках таблиц (тренд цены/продаж) — нужны per-row тренд-данные из API.
- Сравнение с конкурентами инлайн (модуль конкурентов уже есть).

**Надёжность / доверие**
- Undo для массовых операций (инфра snapshot/rollback уже есть для агента — дать user-facing).
- Ретрай упавших операций (один клик «повторить» для failed публикации/обогащения/цен).
- Дайджест ошибок — вечерняя сводка «что не прошло».

**ИИ-рычаг**
- Утренний ИИ-бриф — «за ночь: +12 заказов, 2 карточки просели, 1 ушла в тень».
- NL-команды из ⌘K — «подними цену на 5% на все куртки» → план→подтверждение (безопасный путь).
- Богатый preview proposal — before/after контента + влияние на маржу перед подтверждением.

**Контент / карточки**
- Шаблоны контента (title/description с плейсхолдерами).
- Пробелы по ключевым словам vs топ-конкуренты.

**Рутина**
- Планировщик отчётов (аналитика/финансы на почту по расписанию).
- Онбординг-тур первого входа (⌘K, Фотостудия, трей, кокпит).

## Рекомендация по старту

Кокпит «что делать сегодня» (#1) + проактивные алерты (#2): вместе превращают платформу из
набора экранов в ассистента, который говорит, где нужен продавец, и почти целиком лежат на
готовых данных + системе уведомлений. Затем — здоровье задач/реапер (#3, чинит реальную
болячку) и панель массовых действий (#4 из очереди).
