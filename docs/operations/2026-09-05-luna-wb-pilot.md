# Пилот Luna Max: 5 сентября 2026

Запущены два парсера `gpt-5.6-luna`, `reasoning_effort=max`. Root выполнил подготовку источников, проверку каждой карточки, один возврат на исправление и повторную проверку существующим валидатором Seller Hub. Рабочая БД открывалась только для чтения; записи в товары и WB не выполнялись.

## Исходное состояние

Read-only аудит рабочей БД выявил 21 828 товаров двух поставщиков: 15 706 и 6 122. Сохранённая средняя заполненность составляла 43,7% и 41,7%; это историческая метрика, а не новая проверка готовности каждой карточки.

У 8 006 товаров (5 164 + 2 842) указан `wb_subject_id=5038`, «Товары для взрослых». Этот ID отсутствует среди конечных предметов текущего локального WB snapshot. Поэтому увеличение количества заполненных полей без исправления категории не делает такие карточки готовыми к загрузке.

Общие справочники WB имеют статус `partial`: страны проверены успешно, у цветов/пола/сезона/НДС наблюдались failed scopes. Недоступные поля не выдавались модели для заполнения. Для стран оркестратор дополнительно получил буквальные значения из полного текущего справочника, чтобы его первые 100 строк не скрыли наблюдённую «Россию».

## Что проверено

Пилот включал 12 карточек с проблемным предметом, по 6 от каждого поставщика. Выборка целевая; её результат не оценивает статистически качество всего каталога.

| Этап | Результат |
| --- | --- |
| Категории, первый проход Luna | 10 предложений, 2 `needs_review` |
| Просмотр root всех 12 категорий | 8 допущены к разбору характеристик; 4 оставлены для review |
| Характеристики 8 допущенных карточек | 35 первоначальных предложений полей |
| Найденный дефект | У одного товара 4 исходных материала обрезаны до 3 из-за `max_count` |
| Исправление | Один correction-pass; поле целиком исключено из предлагаемого изменения и оставлено для review |
| Итоговые предложения | 34 поля на 8 карточках |
| Offline exact-set/schema/evidence check | Все итоговые чанки прошли |
| Существующий `validate_wb_characteristics` на рабочем read-only snapshot | Все 8 патчей прошли; source, revision и schema hash не изменились |
| Записано в SupplierProduct / канонические карточки / WB | 0 / 0 / 0 |

Четыре review-карточки: два комплекта обычного белья с неоднозначной adult-классификацией, косметическое средство с выключенной обычной категорией и батарейки, находившиеся у поставщика внутри раздела «Секс-игрушки». Оркестратор не подменял недоступные правильные категории ближайшей включённой adult-категорией.

Дополнительно проверено, что парсеры не выводили страну производства из адреса изготовителя, не выбирали одно число из нескольких размеров частей, не превращали упаковочные габариты в размеры товара и не извлекали спорные свойства из повреждённого описания. Незаданные факты и недоступные словарные поля остались пропусками. Материальный дефект первого прохода показывает, зачем после JSON/schema check нужен смысловой review.

34 поля — проверенные предложения, не утверждение о 34 новых полях в существующих WB карточках. Проверка патча не включает brand binding, полный live WB payload, сохранение всех untouched полей, подтверждение публикации или модерацию WB. `ready_for_wb=false` сохранён во всех отчётах.

## Контрольная точка

Закрытый журнал: `data/luna_parsing_runs/2026-09-05-pilot/` (исключён из Git). Он содержит исходные входы, первоначальные и исправленные ответы, hashes, offline validation, финальную проверку patch/source/revision/schema и решения root по конкретным IDs. Содержимое карточек в этот отчёт не скопировано.

Выполнено 5 задач парсеров: 2 категоризации, 2 разбора характеристик и 1 исправление. Это не число физических LLM requests. Provider token/cost telemetry для этих subagent-задач здесь недоступна и не приравнивается к нулю.

Следующая волна удержана до разбора category coverage и reference failures. Постоянный backend worker и автоматический приём внешнего JSON в production этим пилотом не создавались. Дальнейшее применение требует существующего audited сервиса либо отдельно реализованного и протестированного bridge с source/reference/revision gates; прямая SQL-запись файлов Luna запрещена. Для WB также нужен exact seller/account scope и штатный канал отправки со сверкой результата. Фоновая работа после окончания Codex-сессии не запланирована.

Проверки кода: 13 synthetic unit tests, `py_compile` и `git diff --check` прошли. Тесты не вызывали WB или LLM.
