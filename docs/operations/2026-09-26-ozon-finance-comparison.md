## Поведение

Из финансового журнала доступна Vue-страница «История начислений». Пользователь выбирает две завершённые загрузки и видит общий календарный период, отдельные валютные итоги до/после и различия по exact accrual_id. Перед сравнением под каждым полем видны даты его загрузки; если более ранней подходящей версии нет, предложено выбрать другую пару.

Сдвиг rolling window не превращает ушедшие даты в пропавшие начисления. Разница суммы, валюты, даты, категории, номера, SKU и компонентов различаются; текущие названия услуг, локальные ссылки и порядок строк не меняют финансовый факт. Nested components остаются пояснением и не складываются второй раз. Наблюдённый ноль и отсутствие строки разделены.

Страница показывает различия сохранённых наблюдений. Она не доказывает возврат/отмену/причину корректировки, не рассчитывает прибыль и не заменяет бухгалтерский отчёт Ozon. Ссылки открывают точную версию каждого начисления. Пара/filter/page закреплены в URL; ошибка или новый выбор сохраняют прежний результат с явной подписью, чужая/удалённая/незавершённая версия не заменяется latest.

## Контракт и бюджеты

Шесть runtime-файлов: новый comparison service, existing finance routes/main template, новый Vue template/JS/CSS. Схема, migrations, provider endpoints, scheduler и зависимости не менялись. Финансовые данные не изменяются; decrypt/provider/LLM/job enqueue отсутствуют.

История ограничена 16 completed/current-contract строками + truncation; exact anchor возвращается отдельно, без смены версии. Read имеет один consistent SQLite snapshot, SQL progress budget 5s и busy timeout 200ms с восстановлением handler/timeout перед возвратом соединения. Caps: 10 000 фактов на снимок, 100 000 children всего, 16 MiB текста. Превышение — явный 422 без partial totals. До/после/разница складываются Python Decimal отдельно по currency из top-level total_amount. Полнота каждого snapshot подтверждается fact_count и scope/contract/date проверками.
