# Отзывы и вопросы Ozon на Vue

## Что изменилось

Лента обращений и отдельный редактор ответа используют Vue 3 и общую тему Seller Hub. В ленте — реальные фотографии точно связанных товаров, артикулы, статусы, даты, поиск и страницы. В диалоге — полный текст, локальный шаблон/ИИ, ручная правка, сохранение и копирование. Раздел, фильтры и открытое обращение сохраняются в ссылке.

Сохранение создаёт новую локальную версию и оставляет прежнюю в истории. Проверяются версия черновика, исходное обращение, факты карточки и seller/marketplace/account scope. Генерация, начавшаяся раньше ручной правки, не может затереть её. Чужая связь с карточкой не раскрывает название, фотографию или AI facts. HTML и внешние ссылки не исполняются; поиск `%/_` буквальный.

В обоих типах обращений доступ к API показывается отдельно от состояния магазина. Отказ Ozon не выдаётся за установленную причину о тарифе. Черновик не отправляется в Ozon и не меняет статус обращения: полный send/confirm/read-back остаётся открытым W9 gate.

## Проверки

- 137 tests + 38 subtests: сервисы, маршруты/CSRF, tenant isolation, drift/rollback, конкурентная генерация, browser lifecycle, provider transport/ledger, миграция inbox и 41 backup/restore test.
- Изолированное полное Flask-приложение с синтетической БД: 14 сценариев, 72 layouts, light/dark и ширины 1440/768/390/320. Проверены границы диалога/его нижней панели, отсутствие горизонтального overflow, длинный текст, фокус и Escape, URL/reload, поиск/страницы, реальные обработчики template/save с CSRF, копирование, unknown outcome и восстановление результата чтением без повторного POST.
- 19/19 основных фотографий точно связанных строк; одна из 20 строк намеренно не связана и имеет понятный fallback. Изображение — ранее сохранённый media fixture, а отзывы и вопросы синтетические. Standby network=none; provider reads/writes=0, платных LLM calls=0. AI-адаптер подменён только в процессе стендового теста.
- Проверка настоящего Flask-WTF HTML 400 также подтвердила: текст остаётся в редакторе, повторное открытие не попадает в ложное ожидание незавершённой генерации. Это отдельная фронтенд-правка с повторной полной регрессией и стендовой проверкой.
- После визуального просмотра рабочие заголовки диалога уточнены до Inter; display-акцент остаётся только у заголовка страницы. Повторная проверка финального образа включает эту правку. UI проверен по [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md).

## Открытые границы

Ручной refresh пока использует старый bounded HTTP read: один POST до трёх страниц, без автоматического цикла повторов. Незавершённый run продолжает scheduler; перенос запроса в общую durable очередь ещё открыт. Неизвестный POST draft блокирует повтор до наблюдения новой сохранённой версии; optional sessionStorage содержит только IDs/режим, без текста. Реальные отзывы/вопросы текущего production-кабинета могут оставаться недоступны по API; синтетическая проверка не подтверждает тариф или отправку реального ответа.

Полная отправка отзывов/вопросов, buyer price/скидка Ozon, реальный stock-пилот, публикация с подтверждёнными фактами, полная бухгалтерская сверка и остальные A+B gates не закрыты этим выпуском.
