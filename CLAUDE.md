## Правила для Claude Code (workflow, не продуктовые инварианты)

- Субагентов (Agent tool: разведка кода, стилизация шаблонов, ревью-финдеры,
  прочая массовая/механическая работа) запускай с `model: "sonnet"` (Sonnet 5),
  чтобы не сжигать лимиты основной модели сессии. Основная модель выполняет
  только синтез, верификацию находок субагентов и правки, требующие
  максимального качества. Запуск субагента на модели сессии — осознанное
  исключение для действительно сложной задачи, а не дефолт.
